# C_Programming

Programs and assignments for the Logic Building batch in C.

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution:

```sh
gcc Assignments/Assignment_1/program1_1.c -o program1_1
```

Run on macOS or Linux with `./program1_1`, or on Windows with `program1_1.exe`. Each solution has its own `main` function and should be compiled separately. Programs 1_4 and 1_5 prompt for input.

## Folder layout

```text
Assignments/
└── Assignment_1/
    ├── program1_1.c
    ├── program1_2.c
    ├── program1_3.c
    ├── program1_4.c
    └── program1_5.c
```
