# C_Programming

Programs and assignments for the Logic Building batch in C.

## Compile and run

Install GCC or another C compiler. Compile one solution at a time from the repository root. For example:

```sh
gcc Assignments/Assignment_3/program3_1.c -o program3_1
```

Run on macOS or Linux with `./program3_1`, or on Windows with `program3_1.exe`. Each program has its own `main` function and should be compiled separately.

## Folder layout

```text
Assignments/
├── Assignment_1/
│   ├── program1_1.c
│   ├── program1_2.c
│   ├── program1_3.c
│   ├── program1_4.c
│   └── program1_5.c
├── Assignment_2/
│   ├── program2_1.c
│   ├── program2_2.c
│   ├── program2_3.c
│   ├── program2_4.c
│   └── program2_5.c
└── Assignment_3/
    ├── program3_1.c
    ├── program3_2.c
    ├── program3_3.c
    ├── program3_4.c
    └── program3_5.c
```

Each assignment folder has a README with a solution list and compile/run example. Compile individual source files; do not compile multiple assignment files together because each contains its own `main` function.
