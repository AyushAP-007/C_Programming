# C_Programming

Programs and assignments for the Logic Building batch in C.

## Compile and run

Install a C compiler such as GCC. From the repository root, compile a program:

~~~sh
gcc Assignments/Assignment_1/program1_1.c -o program1_1
~~~

Run it on macOS or Linux with ./program1_1, or on Windows with program1_1.exe. Replace the source and output names to run another solution. Programs that read input will prompt for a value.

## Folder layout

~~~text
Assignments/
└── Assignment_1/
    ├── program1_1.c
    ├── program1_2.c
    ├── program1_3.c
    ├── program1_4.c
    └── program1_5.c
~~~
