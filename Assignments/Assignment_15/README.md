# Assignment 15 – C

Five C solutions for the fifteenth Logic Building assignment.

| File | Program |
| --- | --- |
| `program15_1.c` | Accept full name from user and print that name |
| `program15_2.c` | Check whether a number is greater than 100 |
| `program15_3.c` | Check whether two numbers are equal |
| `program15_4.c` | Print multiplication of three numbers |
| `program15_5.c` | Calculate percentage from total and obtained marks |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_15/program15_1.c -o program15_1
```

Run on macOS or Linux with `./program15_1`, or on Windows with `program15_1.exe`. Each source file has its own `main` function and should be compiled separately.
