# Assignment 20 – C

Five C solutions for Assignment 20.

| File | Problem |
| --- | --- |
| program20_1.c | Print asterisks with hashes on the opposite diagonal. |
| program20_2.c | Print asterisks, hashes, and at signs around the opposite diagonal. |
| program20_3.c | Print a square border and opposite diagonal using asterisks. |
| program20_4.c | Print a square border and opposite diagonal, with hashes and dollar signs on either side. |
| program20_5.c | Print the numbers along the square border and main diagonal. |

Compile a solution from the repository root with GCC. For example:

~~~sh
gcc Assignments/Assignment_20/program20_1.c -o program20_1
~~~

Each file contains its own main function and should be compiled separately.
