# Assignment 19 – C

Five C solutions for Assignment 19.

| File | Problem |
| --- | --- |
| program19_1.c | Print an increasing left-aligned triangle of asterisks. |
| program19_2.c | Print a decreasing left-aligned triangle of asterisks. |
| program19_3.c | Print a symbol grid with a dollar sign diagonal, hashes below it, and asterisks above it. |
| program19_4.c | Print a square border and its top-left to bottom-right diagonal using asterisks. |
| program19_5.c | Print increasing values from the current row number through the column count. |

Compile a solution from the repository root with GCC. For example:

~~~sh
gcc Assignments/Assignment_19/program19_1.c -o program19_1
~~~

Each file contains its own main function and should be compiled separately.
