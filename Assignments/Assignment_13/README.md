# Assignment 13 – C

Five C solutions for the thirteenth Logic Building assignment.

| File | Program |
| --- | --- |
| `program13_1.c` | Return the count of even digits in a number |
| `program13_2.c` | Return the count of odd digits in a number |
| `program13_3.c` | Return the count of digits between 3 and 7 |
| `program13_4.c` | Return the multiplication of all digits in a number |
| `program13_5.c` | Return difference between summation of even and odd digits |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_13/program13_1.c -o program13_1
```

Run on macOS or Linux with `./program13_1`, or on Windows with `program13_1.exe`. Each source file has its own `main` function and should be compiled separately.
