# Assignment 14 – C

Five C solutions for the fourteenth Logic Building assignment.

| File | Program |
| --- | --- |
| `program14_1.c` | Display multiplication of factors of a number |
| `program14_2.c` | Display factors of a number in decreasing order |
| `program14_3.c` | Display all non-factors of a number |
| `program14_4.c` | Return summation of all non-factors of a number |
| `program14_5.c` | Return difference between summation of factors and non-factors |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_14/program14_1.c -o program14_1
```

Run on macOS or Linux with `./program14_1`, or on Windows with `program14_1.exe`. Each source file has its own `main` function and should be compiled separately.
