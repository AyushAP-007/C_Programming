# Assignment 23 – C

Five C solutions for the twenty-third Logic Building assignment.

| File | Program |
| --- | --- |
| `program23_1.c` | Convert a string to lowercase |
| `program23_2.c` | Convert a string to uppercase |
| `program23_3.c` | Toggle the case of each character |
| `program23_4.c` | Display only the digits in a string |
| `program23_5.c` | Count whitespace characters in a string |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_23/program23_1.c -o program23_1
```

Run on macOS or Linux with `./program
23
_1`, or on Windows with `program
23
_1.exe`. Each source file has its own `main` function and should be compiled separately.
