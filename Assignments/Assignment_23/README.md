# Assignment 23 – C

Five C solutions for Assignment 23.

| File | Problem |
| --- | --- |
| program23_1.c | Convert a string to lowercase. |
| program23_2.c | Convert a string to uppercase. |
| program23_3.c | Toggle the case of each character in a string. |
| program23_4.c | Display only digit characters from a string. |
| program23_5.c | Count whitespace characters in a string. |

Compile a solution from the repository root with GCC. For example:

~~~sh
gcc Assignments/Assignment_23/program23_1.c -o program23_1
~~~

Each file contains its own main function and should be compiled separately.
