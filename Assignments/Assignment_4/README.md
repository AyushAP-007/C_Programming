# Assignment 4 – C

Five C solutions for the fourth Logic Building assignment.

| File | Program |
| --- | --- |
| `program4_1.c` | Check whether a number is positive, negative, or zero |
| `program4_2.c` | Check whether a number is even or odd |
| `program4_3.c` | Find the greater of two numbers |
| `program4_4.c` | Check voting eligibility based on age |
| `program4_5.c` | Check whether a number is divisible by 5 |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_4/program4_1.c -o program4_1
```

Run on macOS or Linux with `./program4_1`, or on Windows with `program4_1.exe`. Each source file has its own `main` function and should be compiled separately.
