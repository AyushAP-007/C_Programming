# Assignment 7 – C

Five C solutions for Assignment 7.

| File | Problem |
| --- | --- |
| program7_1.c | Write a program which accept number from user and print that number of $ & * on screen. |
| program7_2.c | Write a program which accept number from user and print numbers till that number. |
| program7_3.c | Write a program which accept number from user and print its numbers line. |
| program7_4.c | Write a program which accepts N from user and print all odd numbers up to N. |
| program7_5.c | Write a program which accept N and print first 5 multiples of N. |

Compile a solution from the repository root with GCC. For example:

~~~sh
gcc Assignments/Assignment_7/program7_1.c -o program7_1
~~~

Each file contains its own main function and should be compiled separately.
