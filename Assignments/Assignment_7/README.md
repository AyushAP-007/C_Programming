# Assignment 7 – C

Five C solutions for the seventh Logic Building assignment.

| File | Program |
| --- | --- |
| `program7_1.c` | Print the specified number of `$ *` patterns |
| `program7_2.c` | Print numbers from 1 up to N |
| `program7_3.c` | Print number line from -N to +N |
| `program7_4.c` | Print all odd numbers up to N |
| `program7_5.c` | Print the first 5 multiples of N |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_7/program7_1.c -o program7_1
```

Run on macOS or Linux with `./program7_1`, or on Windows with `program7_1.exe`. Each source file has its own `main` function and should be compiled separately.
