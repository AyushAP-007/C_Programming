# Assignment 12 – C

Five C solutions for the twelfth Logic Building assignment.

| File | Program |
| --- | --- |
| `program12_1.c` | Display digits of a number in reverse order |
| `program12_2.c` | Check whether a number contains zero |
| `program12_3.c` | Count frequency of digit 2 in a number |
| `program12_4.c` | Count frequency of digit 4 in a number |
| `program12_5.c` | Count frequency of digits less than 6 |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_12/program12_1.c -o program12_1
```

Run on macOS or Linux with `./program12_1`, or on Windows with `program12_1.exe`. Each source file has its own `main` function and should be compiled separately.
