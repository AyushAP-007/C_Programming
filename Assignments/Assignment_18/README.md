# Assignment 18 – C

Five C solutions for the eighteenth Logic Building assignment.

| File | Program |
| --- | --- |
| `program18_1.c` | Display * on and below diagonal and # above diagonal |
| `program18_2.c` | Display * above anti-diagonal and # below anti-diagonal |
| `program18_3.c` | Display $ along main diagonal and * in remaining positions |
| `program18_4.c` | Display * on matrix borders and @ in interior positions |
| `program18_5.c` | Display column numbers on border and * in interior |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_18/program18_1.c -o program18_1
```

Run on macOS or Linux with `./program18_1`, or on Windows with `program18_1.exe`. Each source file has its own `main` function and should be compiled separately.
