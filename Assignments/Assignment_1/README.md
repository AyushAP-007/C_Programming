# Assignment 1 – C

Five C solutions for the first Logic Building assignment.

| File | Program |
| --- | --- |
| `program1_1.c` | Divide two numbers |
| `program1_2.c` | Print “Marvellous” five times |
| `program1_3.c` | Print numbers from 5 to 1 |
| `program1_4.c` | Check whether a number is divisible by 5 |
| `program1_5.c` | Print a user-provided number of asterisks |

Compile a solution from the repository root with GCC. For example:

```sh
gcc Assignments/Assignment_1/program1_1.c -o program1_1
```

Run with `./program1_1` on macOS or Linux, or `program1_1.exe` on Windows. Each file contains its own `main` function and should be compiled separately.
