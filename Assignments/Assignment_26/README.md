# Assignment 26 – C

Five C solutions for the twenty-sixth Logic Building assignment.

| File | Program |
| --- | --- |
| `program26_1.c` | Display ASCII symbol, decimal, hexadecimal, and octal values |
| `program26_2.c` | Toggle the case of a character when it is a letter |
| `program26_3.c` | Display letters from a given character through Z or backward through a |
| `program26_4.c` | Check whether a character is one of the specified special symbols |
| `program26_5.c` | Display a character ASCII values in decimal, octal, and hexadecimal |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_26/program26_1.c -o program26_1
```

Run on macOS or Linux with `./program
26
_1`, or on Windows with `program
26
_1.exe`. Each source file has its own `main` function and should be compiled separately.
