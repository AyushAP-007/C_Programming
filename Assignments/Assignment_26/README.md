# Assignment 26 – C

Five C solutions for Assignment 26.

| File | Problem |
| --- | --- |
| program26_1.c | Display the ASCII table with symbol, decimal, hexadecimal, and octal values. |
| program26_2.c | Display a letter with its case toggled, or other characters unchanged. |
| program26_3.c | Display letters from a capital character through Z or backward from a lowercase character through a. |
| program26_4.c | Check whether a character is one of the specified special symbols. |
| program26_5.c | Display a character's ASCII value in decimal, octal, and hexadecimal. |

Compile a solution from the repository root with GCC. For example:

~~~sh
gcc Assignments/Assignment_26/program26_1.c -o program26_1
~~~

Each file contains its own main function and should be compiled separately.
