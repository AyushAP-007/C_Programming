# Assignment 17 – C

Five C solutions for the seventeenth Logic Building assignment.

| File | Program |
| --- | --- |
| `program17_1.c` | Display numbers 1 to 9 sequentially cycling across the matrix |
| `program17_2.c` | Display even numbers on odd rows and odd numbers on even rows |
| `program17_3.c` | Display lowercase alphabets on odd rows and digits on even rows |
| `program17_4.c` | Display positive numbers on odd rows and negative on even rows |
| `program17_5.c` | Display numbers starting from row number and incrementing |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_17/program17_1.c -o program17_1
```

Run on macOS or Linux with `./program17_1`, or on Windows with `program17_1.exe`. Each source file has its own `main` function and should be compiled separately.
