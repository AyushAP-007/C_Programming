# Assignment 5 – C

Five C solutions for the fifth Logic Building assignment.

| File | Program |
| --- | --- |
| `program5_1.c` | Find the greatest of three numbers |
| `program5_2.c` | Check whether a year is a leap year |
| `program5_3.c` | Calculate student grade from marks |
| `program5_4.c` | Check divisibility by 3 and 5 |
| `program5_5.c` | Identify character type (uppercase, lowercase, digit, special) |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_5/program5_1.c -o program5_1
```

Run on macOS or Linux with `./program5_1`, or on Windows with `program5_1.exe`. Each source file has its own `main` function and should be compiled separately.
