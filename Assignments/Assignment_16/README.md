# Assignment 16 – C

Five C solutions for the sixteenth Logic Building assignment.

| File | Program |
| --- | --- |
| `program16_1.c` | Display alphabetical character matrix A to D across columns |
| `program16_2.c` | Display alternating rows of uppercase and lowercase letters |
| `program16_3.c` | Display rows of identical characters incrementing by row |
| `program16_4.c` | Display row numbers in descending order |
| `program16_5.c` | Display sequential incrementing numbers across matrix |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_16/program16_1.c -o program16_1
```

Run on macOS or Linux with `./program16_1`, or on Windows with `program16_1.exe`. Each source file has its own `main` function and should be compiled separately.
