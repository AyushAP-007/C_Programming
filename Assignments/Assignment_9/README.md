# Assignment 9 – C

Five C solutions for the ninth Logic Building assignment.

| File | Program |
| --- | --- |
| `program9_1.c` | Display pattern with asterisks and hashes |
| `program9_2.c` | Convert USD amount to Indian currency (INR) |
| `program9_3.c` | Calculate even factorial of a number |
| `program9_4.c` | Calculate odd factorial of a number |
| `program9_5.c` | Calculate difference between even and odd factorial |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_9/program9_1.c -o program9_1
```

Run on macOS or Linux with `./program9_1`, or on Windows with `program9_1.exe`. Each source file has its own `main` function and should be compiled separately.
