# Assignment 9 – C

Five C solutions for Assignment 9.

| File | Problem |
| --- | --- |
| program9_1.c | Write a program which accept number from user and display below pattern. |
| program9_2.c | Accept amount in US dollar and return its corresponding value in Indian currency. Consider 1$ as 70 rupees. |
| program9_3.c | Write a program to find even factorial of given number. |
| program9_4.c | Write a program to find odd factorial of given number. |
| program9_5.c | Write a program which returns difference between Even factorial and odd factorial of given number. |

Compile a solution from the repository root with GCC. For example:

~~~sh
gcc Assignments/Assignment_9/program9_1.c -o program9_1
~~~

Each file contains its own main function and should be compiled separately.
