# Assignment 24 – C

Five C solutions for the twenty-fourth Logic Building assignment.

| File | Program |
| --- | --- |
| `program24_1.c` | Check whether a character occurs in a string |
| `program24_2.c` | Count occurrences of a character |
| `program24_3.c` | Find the index of the first occurrence of a character |
| `program24_4.c` | Find the index of the last occurrence of a character |
| `program24_5.c` | Reverse a string in place |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_24/program24_1.c -o program24_1
```

Run on macOS or Linux with `./program
24
_1`, or on Windows with `program
24
_1.exe`. Each source file has its own `main` function and should be compiled separately.
