# Assignment 22 – C

Five C solutions for Assignment 22.

| File | Problem |
| --- | --- |
| program22_1.c | Print consecutive uppercase letters starting from A. |
| program22_2.c | Print descending numbers with a hash after each number. |
| program22_3.c | Print ascending numbers with an asterisk after each number. |
| program22_4.c | Print a hash, each ascending number, and an asterisk. |
| program22_5.c | Print the first N even numbers. |

Compile a solution from the repository root with GCC. For example:

~~~sh
gcc Assignments/Assignment_22/program22_1.c -o program22_1
~~~

Each file contains its own main function and should be compiled separately.
