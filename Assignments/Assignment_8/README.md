# Assignment 8 – C

Five C solutions for the eighth Logic Building assignment.

| File | Program |
| --- | --- |
| `program8_1.c` | Classify number as small, medium, or large |
| `program8_2.c` | Display single digit number in word format |
| `program8_3.c` | Calculate factorial of a given number |
| `program8_4.c` | Display multiplication table of a number |
| `program8_5.c` | Display multiplication table in reverse order |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_8/program8_1.c -o program8_1
```

Run on macOS or Linux with `./program8_1`, or on Windows with `program8_1.exe`. Each source file has its own `main` function and should be compiled separately.
