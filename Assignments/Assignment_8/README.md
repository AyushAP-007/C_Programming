# Assignment 8 – C

Five C solutions for Assignment 8.

| File | Problem |
| --- | --- |
| program8_1.c | Write a program which accept number from user and if number is less than 50 then print small, if it is greater than 50 and less than 100 then print medium, if it is greater than 100 then print large. |
| program8_2.c | Accept single digit number from user and print it into word. |
| program8_3.c | Write a program to find factorial of given number. |
| program8_4.c | Write a program which accept number from user and display its table. |
| program8_5.c | Write a program which accept number from user and display its table in reverse order. |

Compile a solution from the repository root with GCC. For example:

~~~sh
gcc Assignments/Assignment_8/program8_1.c -o program8_1
~~~

Each file contains its own main function and should be compiled separately.
