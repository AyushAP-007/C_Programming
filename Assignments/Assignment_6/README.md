# Assignment 6 – C

Five C solutions for the sixth Logic Building assignment.

| File | Program |
| --- | --- |
| `program6_1.c` | Calculate electricity bill based on slab rates |
| `program6_2.c` | Check candidate admission eligibility |
| `program6_3.c` | Calculate shopping discount and final payable amount |
| `program6_4.c` | Check triangle validity from three side lengths |
| `program6_5.c` | Calculate employee bonus based on service years and salary |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_6/program6_1.c -o program6_1
```

Run on macOS or Linux with `./program6_1`, or on Windows with `program6_1.exe`. Each source file has its own `main` function and should be compiled separately.
