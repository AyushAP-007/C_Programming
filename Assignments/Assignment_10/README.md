# Assignment 10 – C

Five C solutions for Assignment 10.

| File | Problem |
| --- | --- |
| program10_1.c | Write a program which accept radius of circle from user and calculate its area. Consider value of PI as 3.14. (Area = PI * Radius * Radius) |
| program10_2.c | Write a program which accept width & height of rectangle from user and calculate its area. (Area = Width * Height) |
| program10_3.c | Write a program which accept distance in kilometre and convert it into meter. (1 kilometre = 1000 Meter) |
| program10_4.c | Write a program which accept temperature in Fahrenheit and convert it into celsius. (1 celsius = (Fahrenheit -32) * (5/9)) |
| program10_5.c | Write a program which accept area in square feet and convert it into square meter. (1 square feet = 0.0929 Square meter) |

Compile a solution from the repository root with GCC. For example:

~~~sh
gcc Assignments/Assignment_10/program10_1.c -o program10_1
~~~

Each file contains its own main function and should be compiled separately.
