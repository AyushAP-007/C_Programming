# Assignment 10 – C

Five C solutions for the tenth Logic Building assignment.

| File | Program |
| --- | --- |
| `program10_1.c` | Calculate area of a circle |
| `program10_2.c` | Calculate area of a rectangle |
| `program10_3.c` | Convert distance from kilometres to metres |
| `program10_4.c` | Convert temperature from Fahrenheit to Celsius |
| `program10_5.c` | Convert area from square feet to square metres |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_10/program10_1.c -o program10_1
```

Run on macOS or Linux with `./program10_1`, or on Windows with `program10_1.exe`. Each source file has its own `main` function and should be compiled separately.
