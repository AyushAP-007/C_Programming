# Assignment 21 – C

Five C solutions for Assignment 21.

| File | Problem |
| --- | --- |
| program21_1.c | Print a rectangular grid of asterisks. |
| program21_2.c | Print ascending column numbers on each row. |
| program21_3.c | Print descending column numbers on each row. |
| program21_4.c | Print alternating asterisks and hashes by column. |
| program21_5.c | Print the row number repeatedly across each row. |

Compile a solution from the repository root with GCC. For example:

~~~sh
gcc Assignments/Assignment_21/program21_1.c -o program21_1
~~~

Each file contains its own main function and should be compiled separately.
