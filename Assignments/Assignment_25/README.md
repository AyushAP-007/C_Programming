# Assignment 25 – C

Five C solutions for the twenty-fifth Logic Building assignment.

| File | Program |
| --- | --- |
| `program25_1.c` | Check whether a character is an alphabet letter |
| `program25_2.c` | Check whether a character is uppercase |
| `program25_3.c` | Check whether a character is a digit |
| `program25_4.c` | Check whether a character is lowercase |
| `program25_5.c` | Display an exam time based on division |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_25/program25_1.c -o program25_1
```

Run on macOS or Linux with `./program
25
_1`, or on Windows with `program
25
_1.exe`. Each source file has its own `main` function and should be compiled separately.
