# Assignment 11 – C

Five C solutions for the eleventh Logic Building assignment.

| File | Program |
| --- | --- |
| `program11_1.c` | Display all numbers in between a given range |
| `program11_2.c` | Display all even numbers in between a given range |
| `program11_3.c` | Return addition of all numbers in between a given positive range |
| `program11_4.c` | Return addition of all even numbers in between a given positive range |
| `program11_5.c` | Display all numbers in between a given range in reverse order |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_11/program11_1.c -o program11_1
```

Run on macOS or Linux with `./program11_1`, or on Windows with `program11_1.exe`. Each source file has its own `main` function and should be compiled separately.
