# Assignment 2 – C

Five C solutions for the second Logic Building assignment.

| File | Program |
| --- | --- |
| `program2_1.c` | Print a number of asterisks using an incrementing loop |
| `program2_2.c` | Print a number of asterisks using a decrementing loop |
| `program2_3.c` | Print `Hello` when the number is below 10; otherwise `Demo` |
| `program2_4.c` | Repeat the first number by the signed frequency |
| `program2_5.c` | Check whether a number is even or odd |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_2/program2_1.c -o program2_1
```

Run on macOS or Linux with `./program2_1`, or on Windows with `program2_1.exe`. Each file has its own `main` function and should be compiled separately. Problem 4 treats a negative frequency as its magnitude and prints spaces between repeated values.
