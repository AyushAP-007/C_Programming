# Assignment 3 – C

Five C solutions for the third Logic Building assignment.

| File | Program |
| --- | --- |
| `program3_1.c` | Print the requested number of even numbers |
| `program3_2.c` | Display factors of a number |
| `program3_3.c` | Display even factors of a number |
| `program3_4.c` | Convert the case of a character |
| `program3_5.c` | Check whether a character is a vowel |

## Compile and run

Install GCC or another C compiler. From the repository root, compile one solution at a time. For example:

```sh
gcc Assignments/Assignment_3/program3_1.c -o program3_1
```

Run on macOS or Linux with `./program3_1`, or on Windows with `program3_1.exe`. Each source file has its own `main` function and should be compiled separately.
